GBA Patch & Play

An emulator and ROM patcher in one page. Bring your own ROM, apply a patch if you like, play on any device, and carry your save with a short code.

Your games

Games are stored in this browser only. Nothing is uploaded.

1

Add a ROM

Any GBA ROM works here, not just Pokémon. Drop in a .gba file (or a .zip containing one).

Pokémon Emerald base ROM: you will need to obtain this yourself. Distributing ROMs is piracy and illegal in most regions.
The legitimate route is dumping a cartridge you own. Search for "how to dump a GBA cartridge" to find the hardware and tools for it.

2

Patch it optional

Hacks and mods come as a small patch file. Add the clean base ROM above, then apply the patch here. No Lunar IPS or other tools needed. Supports .ips, .bps and .ups (also inside a .zip).

Where to find patches

Always get the patch from the hack's own page, and read which base ROM version it needs. A wrong base is the usual reason a patch fails or glitches. These links are to the creators' pages. This site hosts no patches or ROMs.

Emerald Rogue roguelike

A fan-made roguelike built on Pokémon Emerald by Pokabbie. Each run is generated on the fly: you pick your route, catch a team, face randomized gym leaders, and spend your winnings back at a hub that unlocks more over time. There is an EX version (the recommended one) and a Vanilla version that keeps standard Emerald battle rules.

Base ROM: A clean Pokémon Emerald.

Large hack, so the first load takes a moment.

Get the patch on Hackdex
Emerald Kaizo hard mode

A very hard difficulty rebalance of Emerald, made for people who want a real challenge and the basis of most IronMON runs. Expect tougher trainers and far less room for mistakes than the original game.

Base ROM: Clean Pokémon Emerald (USA). It is an IPS patch, so a wrong base will not be caught: use the exact version the thread names.

Open the download thread
IronMON challenge ruleset

IronMON is a challenge format rather than a single hack: one run, high stakes, usually on a Kaizo-style ROM that has also been randomized. Community guides describe three steps: patch Emerald with Kaizo here, randomize it with the desktop Universal Pokémon Randomizer using the IronMON settings, then add the resulting ROM back here as a new game. The Ironmon Tracker overlay is a BizHawk script for desktop and does not run in a browser.

Base ROM: Clean Pokémon Emerald, then Kaizo, then the randomizer.

Ironmon Tracker on GitHub
Pokémon Modern Emerald quality of life

A modernization of Emerald: double-speed battles, following Pokémon, a better Battle Frontier and many other quality-of-life changes. Patch a clean Emerald, not one already patched with something else. New versions can break old saves.

Base ROM: A clean Pokémon Emerald.

Open the release thread
Pokémon Too Many Types new type chart

A fan-made Emerald hack that blows up the type chart from 18 types to dozens, lets Pokémon carry up to three types, and adds new and reworked moves. Gym leaders and the Elite Four use the new types too. A sequel exists with even more types and a new story.

Base ROM: A clean Pokémon Emerald.

Some download sites for this hack are unreliable. Stick to the official links.

Go to the official site
Super Mariomon crossover

A big fan-made Emerald hack from Too Many Productions that turns the Mushroom Kingdom into a Pokémon-style region, with Mario characters as catchable "Mariomon", a new region and a full post-game. It ships as a BPS patch, so this page can verify it. The team warns that only its official links are safe.

Base ROM: A clean Pokémon Emerald (USA / Europe).

Go to the official site

3

Play and save anywhere

Press Play on a game above. Save in the game as you normally would, then open Save in the toolbar to get a short code. On any other device, add the same game, open Save, and enter the code to continue.

Controls: arrows, Z = A, X = B, A / S = L / R, Enter = Start, Backspace = Select, hold Space to fast-forward. On phones, use the on-screen pad.

Emulation by mGBA (compiled to WebAssembly). This site does not include or distribute any games.
